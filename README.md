## 📌 About the Project

KIT CRACKZ is a static event webpage created to practice and demonstrate fundamental **HTML and CSS** concepts.

The webpage provides information about the event, including its schedule, speakers, and contact details.

## ✨ Features

* Event header with title and tagline
* Navigation links
* About the Event section
* Event schedule table
* Speakers section
* Contact form
* CSS hover effects and transitions
* Clean and responsive layout

## 🛠️ Technologies Used

* HTML5
* CSS3
